Atlas is a high-performance web compilation engine engineered specifically for LLMs, autonomous agents, and structured data pipelines. It transforms messy HTML into clean, deterministic GitHub Flavored Markdown (GFM) and structured JSON while stripping 70–90% of navigation chrome, advertising scripts, and styling overhead.

## The LLM Token Tax

Raw HTML is designed for human eyes in graphical web browsers, not for language models. A typical web page contains megabytes of styling, nested layout divs, telemetry scripts, and boilerplate navigation menus. Feeding raw HTML into LLM context windows causes:

1. **Context Window Saturation**: 70% to 90% of your model's context budget is wasted on non-substantive structural noise.
2. **Degraded Reasoning Fidelity**: Dense script tags and deeply nested DOM trees dilute model attention, increasing hallucinations.
3. **Escalating Inference Costs**: You pay token fees for every byte of navigation chrome and tracking script ingested.

```
Raw Web Page (1.4 MB HTML)
  ├── 850 KB: Tracking scripts, CSS bundles, ads
  ├── 350 KB: Navigation bars, footers, cookie banners
  └── 200 KB: Real substantive article content
        │
        ▼ Atlas Compiler Pipeline
  Pruned Markdown & Structured JSON (~14 KB)
  ✔ 85%+ Context Reduction  ✔ Preserved Tables & Code Blocks  ✔ Deterministic Formatting
```

Atlas solves the token tax by compiling web content at the edge before it ever reaches your models.

## Quick Example

Compile any public URL into token-efficient markdown in a single request:

<CodeGroup>

```bash cURL
curl -X POST https://api.atlas-compiler.com/v1/scrape \
  -H "Authorization: Bearer atlas_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com"}'
```

```typescript TypeScript
import { AtlasClient } from '@atlascompiler/sdk';

const client = new AtlasClient({
  apiKey: process.env.ATLAS_API_KEY,
});

const response = await client.scrape({
  url: 'https://example.com',
});

console.log(response.value.data.markdown);
```

```python Python
import os
from atlascompiler import AtlasClient

with AtlasClient(os.getenv("ATLAS_API_KEY")) as client:
    response = client.scrape({"url": "https://example.com"})
    print(response.value["data"]["markdown"])
```

```go Go
package main

import (
	"context"
	"fmt"
	"log"
	"os"

	"go.atlas-compiler.com/sdk"
)

func main() {
	client := atlas.New(os.Getenv("ATLAS_API_KEY"))
	res, _, err := client.Scrape(context.Background(), atlas.ScrapeUrlRequest{
		Url: "https://example.com",
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(res.Response200.Data.Markdown)
}
```
