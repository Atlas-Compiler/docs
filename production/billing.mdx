## Credit Consumption Matrix

Credits represent units of deterministic edge computation:

| Operation | Credit Cost | Notes |
| :--- | :--- | :--- |
| **Scrape** (`POST /v1/scrape`) | **1 credit** | Per successful page extraction. |
| **Compile** (`POST /v1/compile`) | **1 credit** | Per successful visual compilation. |
| **Map** (`POST /v1/map`) | **1 credit** | Per domain mapping execution (up to 10,000 URLs). |
| **Crawl** (`POST /v1/crawls`) | **1 credit / page** | Billed only for successfully compiled pages. Failed URLs are not billed. |
| **Batch** (`POST /v1/batches`) | **1 credit / page** | Billed per successful item. Partial failures do not consume credits. |

<Note>
  **Failed Request Policy**: If Atlas cannot compile a target URL due to an upstream server error, DNS failure, or edge timeout, zero credits are deducted from your balance.
</Note>

## Global Payments via Dodo Payments

Atlas partners with Dodo Payments to provide friction-free global checkout:

- **150+ Supported Currencies**: Prices and invoices are automatically presented in your local currency with purchasing power parity (PPP) adjustments where eligible.
- **Local Payment Methods**: Pay via major credit cards (Visa, Mastercard, Amex), Apple Pay, Google Pay, UPI (India), Pix (Brazil), and SEPA direct debit (Europe).
- **Automated Tax Compliance**: Dodo Payments calculates and remits VAT, GST, and US sales tax automatically, providing compliant tax invoices and receipts.

## Upgrading & Customer Portal

You can initiate plan upgrades, buy on-demand credit top-ups, or access the self-service billing portal programmatically or via the Atlas Dashboard.

### 1. Start Hosted Checkout Session

Create a checkout session to subscribe to a paid plan:

```bash
curl -X POST https://api.atlas-compiler.com/v1/workspaces/ws_123/billing/checkout \
  -H "Authorization: Bearer $ATLAS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "planCode": "pro",
    "billingCycle": "monthly"
  }'
```

Response:
```json
{
  "url": "https://checkout.dodopayments.com/buy/sub_01j7abc..."
}
```

Redirect your user or open the returned `url` to complete checkout securely.

---

### 2. Access the Self-Service Customer Portal

Generate a secure, short-lived customer portal URL to let customers manage payment methods, download PDF invoices, or change plan tiers:

```bash
curl -X POST https://api.atlas-compiler.com/v1/workspaces/ws_123/billing/portal \
  -H "Authorization: Bearer $ATLAS_API_KEY" \
  -H "Content-Type: application/json"
```

Response:
```json
{
  "url": "https://billing.dodopayments.com/p/session_01j7..."
}
```

### 3. Inspecting the Usage Ledger

Every credit deduction, top-up, and plan renewal is recorded in an immutable ledger:

```bash
curl -X GET https://api.atlas-compiler.com/v1/workspaces/ws_123/usage/ledger \
  -H "Authorization: Bearer $ATLAS_API_KEY"
```

Response:
```json
{
  "balance": 24850,
  "entries": [
    {
      "id": "led_01j7abc...",
      "amount": -1,
      "reason": "compile",
      "referenceId": "job_01j7abc...",
      "timestamp": "2026-09-19T12:30:00.000Z"
    }
  ]
}
```
