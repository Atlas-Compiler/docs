## Code Examples

<CodeGroup>
```bash cURL
curl -X POST https://api.atlas-compiler.com/v1/scrape \
  -H "Authorization: Bearer $ATLAS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://news.ycombinator.com",
    "formats": ["markdown", "links"]
  }'
```

```typescript TypeScript
import { AtlasClient } from '@atlascompiler/sdk';

const atlas = new AtlasClient({ apiKey: process.env.ATLAS_API_KEY! });

const result = await atlas.scrape({
  url: 'https://news.ycombinator.com',
  formats: ['markdown', 'links'],
});

console.log('Title:', result.metadata?.title);
console.log('Markdown:\n', result.data.markdown);
```

```python Python
import os
from atlascompiler import AtlasClient

atlas = AtlasClient(api_key=os.environ["ATLAS_API_KEY"])

result = atlas.scrape(
    url="https://news.ycombinator.com",
    formats=["markdown", "links"],
)

print(f"Title: {result.metadata.title}")
print(result.data.markdown)
```

```go Go
package main

import (
	"context"
	"fmt"
	"os"

	"go.atlas-compiler.com/sdk"
)

func main() {
	client := atlas.New(os.Getenv("ATLAS_API_KEY"))

	result, _, err := client.Scrape(context.Background(), atlas.ScrapeUrlRequest{
		Url: "https://news.ycombinator.com",
	})
	if err != nil {
		panic(err)
	}

	fmt.Printf("Title: %s\n", result.Metadata.Title)
	if result.Data.Markdown != nil {
		fmt.Println(*result.Data.Markdown)
	}
}
```

## Response Structure

A successful `200 OK` response contains:
- `data.markdown`: LLM-ready clean Markdown.
- `data.links`: Extracted outbound hyperlinks with anchored text.
- `metadata`: Page title, canonical URL, HTTP status code, and extraction timestamp.
- `usage.credits`: Number of credits deducted for the compilation (default: 1 credit).
