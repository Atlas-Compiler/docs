## Core design principles

All official Atlas SDKs follow consistent architectural standards:

1. **Automatic workspace resolution**: Authenticate using your Atlas API key (`atlas_...`). The SDK and backend resolve your workspace and default project automatically.
2. **Type safety & schema fidelity**: Request parameters, responses, metadata, and error objects are strongly typed according to our public OpenAPI contracts.
3. **Built-in resilience & exponential backoff**: Transient errors (HTTP 429 rate limits, 503 capacity saturation) are automatically retried with jitter when marked retryable.
4. **Idempotency built-in**: Mutating compilation, crawl, and batch requests accept client-provided idempotency keys to ensure zero-duplicate billing on retries.
5. **Zero external dependencies**: Our TypeScript library runs anywhere modern JavaScript executes (Node.js 18+, Bun, Deno, Cloudflare Workers, Next.js Edge).
